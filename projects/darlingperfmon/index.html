darlingperfmon

Grafana dashboards for Erik Darling's PerformanceMonitor, Darling edition.

Run the demo locally (https://github.com/argpna/darlingperfmon):

git clone https://github.com/argpna/darlingperfmon.git
cd darlingperfmon
cp .env.example .env && docker compose --profile darling up -d
