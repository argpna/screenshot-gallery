eriksperfmon

Grafana dashboards for Erik Darling's PerformanceMonitor (Full Edition). Screenshots from a demo running SQL Server 2017-2025 with a synthetic workload: wait stats, blocking pairs, deadlocks, memory pressure etc.

Run the full demo locally (Get it from GitHub - argpna/eriksperfmon):

git clone https://github.com/argpna/eriksperfmon.git
cd eriksperfmon
cp .env.example .env && docker compose up -d
